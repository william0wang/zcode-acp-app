# Automated acceptance manifest: every implemented feature mapped to the
# tests that guard it. Format (one feature per line):
#   feature-id :: Feature description :: kind:filter[,filter...]
# kind: rust   = substring matched against `cargo test` full names
#       vitest = substring matched against mobile test FILE names
#       step   = a runner step id (build | smoke | tsc)
# A feature PASSES when every filter has >= 1 passing test and no failing
# one; a filter with zero matches reports NO COVERAGE (fails the run) —
# this file is the feature inventory, keep it in sync with shipped work.
